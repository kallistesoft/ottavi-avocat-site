# Ottavi Law Firm Inc. — website

Static site for Ottavi Law Firm Inc. (Me Vanessa Poughon). Plain HTML pages generated by `tools/build.py`; the first
version followed the mockup in [`design/`](design/README.md).

## Structure

| FR | EN | Page |
| --- | --- | --- |
| `/` | `/en/` | Home |
| `/services/` | `/en/services/` | Audit, consultation, Alberta ebook |
| `/ressources/` | `/en/resources/` | Free guide and CV template |
| `/cabinet/` | `/en/firm/` | The firm and the lawyer |
| `/contact/` | `/en/contact/` | Email and Calendly booking |

The pages are generated: edit the texts and links in `tools/content.py` (or the templates in `tools/build.py`),
then run

```sh
python3 tools/build.py
```

and commit the regenerated pages (`sitemap.xml` is generated too). Styles are in `assets/site.css` ("Ivoire" theme: ivory background, ink text,
plum `#9B3F78` accent, Fraunces + Inter); `assets/site.js` handles the mobile menu and the notice on the newsletter
form, which isn't connected yet. Links are relative, so the site works at a domain root or in a subfolder. Preview with a local
server:

```sh
python3 -m http.server 8000
```

## Hosting

The site is on the client's own GoDaddy cPanel hosting. Every push to `main` runs the **Deploy to GoDaddy** workflow, which uploads the
site over FTPS with the `OTTAVI_FTP_*` organization secrets (without `design/`, `tools/`, `.github` and the Markdown files).
`.htaccess` sends `http://` and the bare domain to `https://www.ottavilawfirm.com`.
